Membandingkan pendekatan klasik Machine Learning dan Large Language Model (LLM) berbasis API dalam menyelesaikan tugas sentiment analysis, guna memahami cara mengevaluasi performa model dan menyusun rekomendasi teknis berdasarkan hasil eksperimen.

1. # **Deskripsi Assignment**

   # Pada assignment ini, peserta akan melakukan eksperimen dan evaluasi terhadap dua pendekatan AI yang berbeda untuk menyelesaikan use case sentiment analysis terhadap ulasan pelanggan: (1) model klasik Machine Learning yang dilatih sendiri menggunakan Scikit-learn, dan (2) Large Language Model (LLM) yang diakses melalui Gemini AI API menggunakan pendekatan prompting. Peserta akan menjalankan kedua pendekatan pada dataset yang sama, mengukur performanya menggunakan metrik evaluasi yang relevan, kemudian menganalisis kelebihan, keterbatasan, dan trade-off dari masing-masing pendekatan sebelum menyusun rekomendasi technical approach.

2. # **Tujuan Assignment**

* Memahami problem statement dan objective dari sebuah use case AI.  
* Melatih model klasik Machine Learning menggunakan Scikit-learn untuk task klasifikasi teks.  
* Menjalankan inference LLM melalui Gemini AI API menggunakan pendekatan prompting untuk task yang sama.  
* Mengevaluasi performa kedua pendekatan menggunakan metrik evaluasi yang relevan (Accuracy, Precision, Recall, F1-Score).  
* Menganalisis trade-off antara model klasik dan LLM API dari sisi performa, kecepatan implementasi, dan biaya.  
* Menyusun rekomendasi technical approach berdasarkan hasil eksperimen dan analisis.


3. # **Studi Kasus**

   Sebuah tim produk e-commerce ingin membangun fitur otomatis untuk mengklasifikasikan sentimen ulasan pelanggan (positif/negatif) pada halaman produk. Sebelum tim memutuskan pendekatan mana yang akan dipakai di sistem produksi, Anda sebagai AI Engineer diminta melakukan eksperimen awal untuk membandingkan dua kandidat pendekatan berikut, lalu memberikan rekomendasi berbasis data:  
* **Pendekatan 1 \- Model klasik**: Melatih model klasifikasi sendiri menggunakan Scikit-learn di atas dataset ulasan yang tersedia.  
* **Pendekatan 2 \- LLM API**: Memanfaatkan Gemini AI API dengan prompt yang dirancang untuk mengklasifikasikan sentimen tanpa proses training.  
  Hasil eksperimen dan rekomendasi Anda akan menjadi bahan pertimbangan tim dalam menentukan pendekatan mana yang akan dikembangkan lebih lanjut.
